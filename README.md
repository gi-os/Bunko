# Bunko

SwiftUI iOS app. Every push to `main` is a TestFlight build; other branches and PRs run the Check
workflow. Built on the shared gi-os iOS kit: see [gi-os/.github/ios](https://github.com/gi-os/.github/tree/main/ios).

```sh
brew install xcodegen && xcodegen generate && open Bunko.xcodeproj
```
